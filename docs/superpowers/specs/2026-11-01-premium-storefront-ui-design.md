# مذاق — تحسين واجهة المتجر

## الهدف
رفع واجهة متجر مذاق الحالية إلى تجربة عربية RTL أكثر فخامة ووضوحاً على الهاتف وسطح المكتب، مع الحفاظ على هوية الأسود الدافئ والذهبي والبنية الحالية وعدم إعادة بناء التطبيق.

## النطاق
- تحسين التباين والخلفيات والمسافات والتركيز البصري العام.
- تطوير شريط التنقل السفلي ليكون ثابتاً داخل إطار التطبيق، مع مساحة آمنة أسفل المحتوى.
- تحسين بطاقات المنتجات لتكون أكثر اتساقاً ووضوحاً مع حالات صور بديلة وإمكانية وصول أفضل.
- تحسين رأس الصفحة وسلوك الأزرار والانتقالات الدقيقة.
- عدم تغيير منطق الطلبات أو الأسعار أو قاعدة البيانات أو إدخال أي بيانات تجريبية.

## خارج النطاق
- إعادة بناء الخادم أو نظام الحسابات.
- تحويل Android APK في هذه المرحلة.
- تغيير الهوية التجارية أو إدخال محتوى/أسعار افتراضية.

## القيود
- React + TypeScript + Tailwind CSS الحالي.
- دعم RTL والجوال أولاً، وعدم كسر سطح المكتب.
- الحفاظ على المكونات الحالية وواجهات props.

## البدائل
1. إعادة تصميم شاملة من الصفر: مرفوضة لأنها تهدر المكونات العاملة وتزيد مخاطر كسر التدفقات.
2. تحسين تدريجي للمكونات الحالية والأنماط العامة: المختار لأنه يحافظ على الوظائف ويعالج أكبر نقاط الاحتكاك بأقل مخاطرة.
3. تغيير مكتبة الواجهة: غير مناسب حالياً لأنه يضيف اعتماديات ولا توجد حاجة مثبتة له.

## قرارات التنفيذ
- استخدام تحسينات CSS مشتركة مع تعديلات محدودة في Header وProductCard وBottomNavigation وApp.
- إضافة اختبارات آلية صغيرة للثوابت/الواجهات المرئية إن أمكن ضمن إعدادات المشروع الحالية؛ لا ندعي اجتياز اختبارات غير موجودة.
- لا دمج إلى main تلقائياً؛ العمل على فرع مستقل وفتح PR بعد التحقق.
