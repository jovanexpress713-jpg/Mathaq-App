# خطة تنفيذ أسعار الأفراد والجملة وحسابات البقالات

## Task 1 — نماذج البيانات والتوافق
- أضف wholesalePrice?: number إلى Product.
- أضف AccountType وحالة حساب بقالة وحقل accountType إلى CustomerInfo/Order حسب الحاجة.
- أضف لقطة accountType وunitPrice إلى OrderItemSnapshot.
- حافظ على قراءة البيانات القديمة مع افتراض الفرد وعدم وجود سعر جملة.

## Task 2 — إدارة الأسعار
- أضف إدخال سعر الجملة إلى نموذج إضافة/تعديل المنتج.
- تحقق من أن السعر رقم غير سالب، وأن الحقل الفارغ يعني غير متاح للجملة.
- اعرض حالة عدم ضبط سعر الجملة بوضوح.

## Task 3 — تسجيل حساب البقالة واعتماده
- أضف تخزين طلبات حسابات البقالات وحالات PENDING/APPROVED/REJECTED.
- أضف endpoints آمنة للتسجيل والاستعلام عن حالة الحساب.
- أضف تبويباً إدارياً لمراجعة الطلبات واعتمادها أو رفضها.
- لا تسمح للعميل بتعيين حالة APPROVED بنفسه.

## Task 4 — checkout والأسعار الخادمية
- أضف اختيار فرد/بقالة بعد الوصول إلى إتمام الطلب.
- اجمع بيانات المتجر عند اختيار بقالة.
- امنع إتمام طلب الجملة قبل اعتماد الحساب.
- احسب الخادم سعر كل منتج بحسب نوع الحساب، ولا تثق بأي سعر مرسل من العميل.
- احفظ سعر الوحدة ونوع الحساب في الطلب.
- احتفظ بمسار الطلب الفردي الحالي.

## Task 5 — التحقق
- اختبر حساب الفرد والسعر الأساسي.
- اختبر حساب بقالة معتمد وسعر الجملة.
- اختبر بقالة غير معتمدة ورفض الطلب.
- اختبر منتجاً بلا سعر جملة ورفض طلبه بالجملة.
- اختبر أن تعديل السعر لا يغير الطلبات السابقة.
- شغّل npm run lint وnpm run build إن أمكن، وسجل النتائج الفعلية.
