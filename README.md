# مذاق | MAZAQ

متجر إلكتروني عربي مع خادم Express ولوحة إدارة وطلبات وحسابات بقالات بأسعار جملة.

## التشغيل المحلي
يتطلب Node.js 20 أو أحدث.
```bash
npm install
cp .env.example .env
npm run dev
```
يفتح التطبيق على `http://localhost:3000`.

## الفحوصات والبناء
```bash
npm run lint
npm test
npm run build
npm start
```

## إعداد الإنتاج
اضبط `NODE_ENV=production` و`PORT=3000`، ثم عيّن:
- `MAZAQ_DATA_DIR`: مجلد قاعدة البيانات الدائم.
- `MAZAQ_UPLOADS_DIR`: مجلد الصور الدائم.
- `MAZAQ_INITIAL_ADMIN_PASSWORD`: كلمة مرور قوية وفريدة عند إنشاء قاعدة جديدة فقط.

يجب أن يكون مجلدا البيانات والصور على تخزين دائم. لا تستخدم نظام ملفات مؤقتاً أو serverless runtime. لا تشغّل أكثر من نسخة خادم تكتب إلى ملف JSON نفسه.

## Docker
انسخ `.env.example` إلى `.env` محلياً، واضبط كلمة مرور المدير في الملف، ثم شغّل:
```bash
docker compose up --build -d
```
تُحفظ قاعدة البيانات والصور في volume دائم باسم `mazaq_data`. افحص `/api/health`، واحتفظ بنسخ احتياطية خارج الخادم واختبر الاستعادة قبل استقبال طلبات حقيقية.

## بيانات المتجر
- يبدأ المتجر الجديد بكتالوج فارغ وطلبات وحسابات فارغة؛ أدخل المنتجات والأسعار والعروض ومناطق التوصيل الحقيقية من لوحة الإدارة قبل تفعيل استقبال الطلبات.
- بيانات قاعدة التشغيل والصور والنسخ الاحتياطية وملفات `.env` مستثناة من Git.
- لا تحذف الطلبات أو الحسابات عند إفراغ الكتالوج.
- يحتفظ النظام بنسخة قاعدة سليمة قبل كل استبدال ناجح، ويتوقف إذا تعذرت قراءة قاعدة البيانات بدلاً من الكتابة فوقها ببيانات افتراضية.
- تخزين JSON الحالي لخادم واحد فقط، وليس مناسباً لتشغيل عدة نسخ متزامنة.

## تطبيق Android
- يبني سير العمل ملف APK تجريبياً عبر GitHub Actions.
- قبل إعادة بناء APK للاستخدام الفعلي، أضف متغير مستودع GitHub باسم `MAZAQ_API_BASE_URL` وقيمته عنوان خادم MAZAQ العام دون `/api`، مثل `https://your-domain.example`.
- أضف أصل التطبيق إلى `MAZAQ_CORS_ORIGINS` في بيئة الخادم، مع `capacitor://localhost` المسموح افتراضياً.
- إذا لم يُضبط عنوان API، فستعمل واجهة التطبيق محلياً لكن لن تتصل بقاعدة الطلبات والإدارة.

## الدفع
الدفع عبر واتساب هو التدفق المفعّل. لا توجد بوابة دفع إلكترونية مدمجة.

## حالة النشر
هذه التغييرات تجهّز التطبيق لحاوية Node.js مع تخزين دائم. لا تعني أنه نُشر على الإنترنت أو أن مزود استضافة مجاني قد تم اختياره. قبل الإطلاق العام، اختبر حفظ البيانات والصور بعد إعادة التشغيل واستعادة النسخ الاحتياطية.
