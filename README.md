# مذاق | MAZAQ

واجهة متجر إلكتروني عربية مع خادم Express، لوحة إدارة، طلبات، وحسابات بقالات بأسعار جملة.

## متطلبات التشغيل

- Node.js 20 أو أحدث
- npm
- مجلد بيانات دائم وقابل للكتابة على الخادم

## التطوير المحلي

```bash
npm install
cp .env.example .env
# في التطوير المحلي يمكن ترك NODE_ENV غير مضبوط
npm run dev
``

يفتح التطبيق على `http://localhost:3000`.

## الفحوصات والبناء

```bash
npm run lint
npm test
npm run build
npm start
``

## تشغيل الإنتاج وحفظ البيانات

- اضبط `NODE_ENV=production`.
- اضبط `PORT` حسب المنصة.
- اربط `MAZAQ_DATA_DIR` بمجلد دائم (Persistent Disk/Volume)، وليس نظام ملفات مؤقتاً.
- اضبط `MAZAQ_INITIAL_ADMIN_PASSWORD` بكلمة مرور قوية وفريدة قبل أول تشغيل ينشئ قاعدة البيانات.
- لا ترفع ملف `.env` أو قاعدة البيانات أو النسخ الاحتياطية إلى Git.
- يبدأ المتجر الجديد بكتالوج فارغ وطلبات وحسابات فارغة؛ لا توجد منتجات أو أسعار أو طلبات أو عروض أو مناطق توصيل تجريبية. أدخل بيانات نشاطك الفعلية من لوحة الإدارة قبل تفعيل استقبال الطلبات.\n- زر إفراغ الكتالوج يمسح الأقسام والمنتجات والعروض فقط، ولا يمسح الطلبات أو حسابات العملاء أو إعدادات المتجر.\n- يحتفظ الخادم بنسخة سليمة أخيرة من قاعدة البيانات في `mazaq_db.json.bak` قبل كل استبدال ناجح.
- إذا تعذرت قراءة قاعدة البيانات، يتوقف الخادم ويحتفظ بالملف المتضرر كنسخة `.corrupt.*.bak` بدلاً من استبداله تلقائياً ببيانات افتراضية.

**مهم:** البيانات الموجودة في قاعدة قديمة لا تُمسح تلقائياً عند التحديث؛ تغيير التهيئة الفارغة ينطبق على قاعدة جديدة فقط. راجع قاعدة التشغيل قبل نشرها حتى لا تختلط بيانات العرض القديمة بالبيانات الحقيقية.\n\n**مهم:** قاعدة البيانات الحالية JSON محلية لنسخة خادم واحدة. لا تشغّل أكثر من نسخة/عامل خادم يكتب إلى نفس الملف، ولا تستخدم تخزيناً مؤقتاً أو serverless filesystem. قبل استقبال طلبات حقيقية، اختبر استعادة النسخة الاحتياطية فعلياً، وغيّر كلمة مرور المدير إذا كانت قاعدة بيانات قديمة قد أُنشئت سابقاً بالقيمة الافتراضية.

## الدفع والطلبات

- الدفع عبر واتساب هو التدفق المفعّل في واجهة المتجر حالياً.
- لا توجد بوابة دفع إلكترونية مدمجة؛ لا يعتبر الخادم بيانات بطاقة العميل إثباتاً للدفع.
- يحدد الخادم أسعار المنتجات وخياراتها ومجموع الطلب، ولا يعتمد أسعار العميل المرسلة.
- سعر الجملة لا يتاح إلا لحساب بقالة معتمد.
